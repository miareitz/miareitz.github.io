**Overview:**
This project turns conference listings and calls for papers into a readable timeline view, with extra focus on location data and HPC-related filtering.

![CFP Timeline Fork screenshot](/assets/img/projects/cfp-timeline.png)

**What it does:**
*   Cross-references conference lists with WikiCFP calls for papers.
*   Presents the results on a timeline for easier browsing.
*   Extends the original project with location and HPC filtering.
